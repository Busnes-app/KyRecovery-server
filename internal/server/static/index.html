Backup retention

Keep all recent backups plus the newest per UTC calendar week and month for each paired product. Each window counts back from today and overlaps the others: for example, all backups for 14 days, weekly backups for 8 weeks, and monthly backups for 12 months. Daily 0 keeps everything forever; weekly/monthly 0 disables that tier. Saving does not delete anything. Manual purge can remove the last backup beyond all windows. Offsite copies require their own retention policy.

Destination

Credentials

Legacy SMB uses NTLMv2 authentication with known cryptographic limitations and no forward secrecy. A captured or relayed authentication exchange can expose this credential. Use a dedicated account and a unique strong password on a trusted network; never reuse a suite administrator password. Message signing is required, so unsigned guest sessions are refused. The strong-crypto profile disables SMB. Prefer pinned SFTP or verified HTTPS S3. A host-mounted share needs its own strong authentication policy; mounting alone does not remove NTLM.
