# Everyday tasks

## Deposits and integrity

Products seal their own capsules and deposit them with their own scoped tokens. Review the newest capsule, digest, size and deposit time. Verification re-hashes stored bytes; it does not open the capsule or prove that the product collected every required file.

## Custody and restore

Keep custodian cards separate from the running server. Download the selected capsule using an operator session and run the product's restore command on the operator's machine. Enter enough shares through stdin, never command arguments or the KyRecovery server.

## Unpairing

The product administrator removes its destination/token while retaining its key pin. A KyRecovery administrator separately revokes the product token. Both steps are needed; a product deposit token cannot revoke itself or download backups.

## Retention and replicas

Review retention and offsite replication deliberately. Preserve receipts and the audit ledger. Verify an actual recovery copy before deleting retained capsules or changing storage destinations.
