# Getting started

## Deploy and protect the store

Follow the product reference for persistent storage, server keys, HTTPS and administrator sign-in. Preserve the audit key and ledger along with the database and capsule files.

## Run the suite ceremony

An administrator opens `/admin/ceremony` in a fresh private browser window without extensions. Choose threshold k and total n. Do a throwaway print-preview rehearsal first, discard it without importing, then generate/print the real custodian cards. Confirm only the public key/topology import and close the tab. Keep the machine from hibernating during the ceremony.

## Pair a product

Generate a six-digit pairing code for the correct service and give it to the product administrator out of band. Claims require an imported recovery public key. Verify the product pins that key and performs a deposit whose receipt digest matches its sealed bytes.
